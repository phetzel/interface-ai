# interface-ai

Planning for a computer-use automation system: LLM-driven discovery, a reusable capability artifact, deterministic replay, policy enforcement, and human takeover of the same live session.

**Status: planning only.** No application, agent, replay engine, dependencies, or runnable demo has been implemented. The recommendations below are proposals, not completed features.

- [Options and recommended decisions](docs/DECISIONS.md)

The repository starts private during preparation. The assignment requires a public repository for submission.

## Intended demonstration

A real model navigates a local sample application to find a synthetic member's savings balance. The system records a typed, parameterized capability. That capability is replayed for another member without model calls. Additional scenarios demonstrate business outcomes, recovery, policy enforcement, and human intervention.

## Eventual submission requirements

- This README: actual setup/configuration and exact discovery/replay commands.
- `REPORT.md`: approximately 1–3 pages using the assignment's seven required headings.
- `evidence/`: a real saved capability and sanitized logs from discovery and replay; include an exceptional run.

The assignment PDF is not included. No model credentials, live customer data, or fabricated execution evidence should be committed.
